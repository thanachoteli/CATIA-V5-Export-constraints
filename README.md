# CATIA Code to export the sketch constraints to CSV file
1. Make sure all dependencie is installed: pycatia (https://pycatia.readthedocs.io/en/latest/installation.html)
2. Then git clone this repo 
```python
git clone https://github.com/thanachoteli/CATIA-V5-Export-constraints.git
```
3. Open the terminal/command prompt
4. Open terminal. Make sure that the terminal is in the same folder as this repository
5. Copy the code below and run while CATIA is opened with the sketch file. 
```
python Export_Sketch_Constraints_To_CSV.py
```
The code should produce the CSV which contain the sketch constraints
